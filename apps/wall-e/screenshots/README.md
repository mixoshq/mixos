# Screenshots

Catalogue listing images for this app. Drop `.png` / `.jpg` / `.webp` files here
and declare them in `app.json`:

```json
"screenshots": [
  { "file": "screenshots/dashboard.png", "alt": "…", "caption": "…" }
]
```

Limits the build enforces: no SVG, at most 8, at most 2 MB each, at least 640px
wide. Full convention in
[`apps/_template/screenshots/README.md`](../../_template/screenshots/README.md).
