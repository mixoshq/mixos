# Welcome tour

## Context

The first-run experience was a react-joyride tour behind a four-slide modal.
It was stripped in preparation for this redesign; only a stubbed "Replay
welcome tour" card in Preferences and the `users.onboarding_completed_at`
column survived. This plan is the redesign.

## Decisions

- **Trigger:** plays when `onboarding_completed_at` is null. Completion is
  stamped when the guide's last step is dismissed, or on Skip. The Preferences
  replay button clears the stamp and returns to `/`.
- **It starts on the sign-in page.** On submit the card's frame and fields
  fade out; the logo (mark over wordmark) stays. The server redirects to the
  dashboard, where the takeover renders the sign-in page's own layout — the
  same `LoginLockup`, and the sign-in fields as an invisible ghost so the
  card is exactly as tall — so the logo has not moved a pixel. No flash of
  the dashboard: the overlay is server-rendered with the page. A failed
  attempt fades the fields back in and shakes the card, keeping the email.
- **Copy is choreographed in beats, over the ghost form:**
  1. *Welcome to MixOS, your new home base.* (small, one line) fades in;
     one second later the "workspace of apps" line; then Next.
  2. Next fades everything out, then the "MixOS exists to make that more
     possible…" paragraph fades in, alone; then Next.
  3. *Let computers do computer things so humans can do human things.* fades
     in; 1.5 s later, "Let's begin".
- **The reveal is the menu bar being born.** On "Let's begin" the copy
  fades, then the mark and the wordmark each fly (FLIP: measured translate +
  uniform scale) to their counterpart in the header lockup, then the
  overlay's height collapses to the header's bottom edge. Both are
  `bg-brand`, so the overlay's last frame is pixel-identical to the bar and
  it unmounts without a seam.
- **Guide: six steps, three of them real actions.** A `Guide` takes
  `[{ target, title, body, placement?, along?, advance?, done?, dim? }]`,
  measures the target each frame, portals a spotlight (box-shadow cut-out,
  pointer-events none — the dashboard stays live) and a bubble whose arrow
  follows the target. `advance: "auto"` steps have no Next: they move on
  when `done()` sees the asked-for change in the DOM.
  1. Menu bar (bubble 30% along it) — Next.
  2. Apps button: installed apps, and App Manager for more — Next.
  3. "Everything else is your dashboard" on the Edit Dashboard button (or
     the pencil once widgets exist) — advances when the catalog is open.
     Entering edit mode opens the catalog by itself on an empty dashboard,
     and always while the tour is running, so there is no "click Add
     Widget" step.
  4. The Wall-E card — no dim, and the catalog drops its own backdrop while
     the tour runs — advances when the catalog closes with a Wall-E widget
     on the dashboard.
  5. Done Editing Dashboard — advances when the pencil is back.
  6. The pencil, bottom-right: "That's all for now" — Done, then **confetti**.
  "Skip tour" sits in every bubble but the last.
- **Wall-E is installed on first sign-in.** `ensureUser` installs every
  `global` app for a user whose tour is not yet finished — idempotent, so it
  also covers the seeded first admin — after which it is theirs to
  uninstall. That is what guarantees step 4 has a card to point at.
- **Confetti on Done, not on Skip.** 480 CSS pieces in theme colours,
  deterministically scattered (render must be pure), pointer-events off,
  gone after ~3.4 s.
- **Menu bar forced visible** while the tour is active, so an auto-hide
  preference cannot hide the thing the guide points at.
- **Reduced motion:** the reveal becomes a 300 ms fade. Screens still fade.
- **No Skip on the three full-screen slides.** "Skip tour" appears in the
  guide bubbles (every step but the last) and counts as completion.

## File-level changes

- `src/lib/onboarding/actions.ts` — `getOnboardingCompletedAt`,
  `markOnboardingComplete`, `resetOnboarding` (recreated).
- `src/components/onboarding/tour-context.tsx` — `TourProvider` /
  `useTour`: `phase` (`welcome | reveal | guide | done`), `begin()`,
  `finish()`. Initial phase from a server prop; a later `true` (replay) restarts.
- `src/components/onboarding/welcome-tour.tsx` — the overlay: the sign-in
  layout with a ghost form, the beat choreography, Skip, the two FLIPs +
  collapse reveal.
- `src/components/login-lockup.tsx` — mark over wordmark, shared by the
  sign-in card and the takeover; carries the `data-tour` hooks.
- `src/app/(auth)/login/login-card.tsx` — the sign-in card (replaces
  `credentials-form.tsx`): fades on submit, shakes on failure.
- `src/app/(auth)/login/credentials-fields.tsx` — the fields, presentation
  only, with a `ghost` mode for the takeover.
- `src/app/(auth)/login/actions.ts` — state gains `attempt` (so a repeat
  failure shakes again) and `email` (so it is not emptied).
- `src/components/onboarding/guide.tsx` + `steps.ts` — the step framework
  and the six steps; `confetti.tsx` — the finale.
- `src/lib/apps/access.ts` — `ensureUser` installs global apps until the
  tour is done; `docs/apps/architecture.md` says so on `global`.
- `data-tour` hooks: `apps-menu` (Apps button), `edit-dashboard`,
  `dashboard-pencil`, `add-widget`, `done-editing`, `widget-<slug>` (catalog
  card), `data-tour-widget-instance=<slug>` (a placed widget).
- `src/components/dashboard/grid.tsx` — entering edit mode opens the
  catalog on an empty dashboard or during the tour; `widget-catalog.tsx`
  gains a `backdrop` prop the tour turns off.
- `src/app/(main)/layout.tsx` — fetches the stamp, wraps in `TourProvider`,
  mounts `WelcomeTour` and `Guide`.
- `src/components/header.tsx` — `data-tour="menu-bar"` on the bar,
  `data-tour="menu-bar-logo"` on the lockup link.
- `src/components/header-shell.tsx` — inline (never auto-hidden) while the
  tour is active.
- `src/components/onboarding/replay-button.tsx` — wired to `resetOnboarding`.
- `src/app/globals.css` — the guide bubble's fade-in, the sign-in shake, and
  the confetti fall.

## Verification

- Fresh user: sign in → form fades, logo does not move (compare its rect on
  `/login` and in the takeover), beats in order with their pauses, "Let's
  begin" → mark and wordmark land on the header's with no jump, bar forms,
  the six steps in order — the three action steps advance only on the
  action, Wall-E is in the catalog for a user with no apps — Done →
  confetti → dashboard; reload → no tour.
- Wrong password → card shakes, error shows, email still filled; a second
  wrong password shakes again.
- Skip tour from the first bubble → dashboard, reload → no tour.
- Preferences → Replay → tour plays again from screen 1.
- Menu bar set to auto-hide before replay → bar stays visible through the
  callout, hides again after Done.
- OS reduced motion → fade instead of fly/collapse; nothing overlaps.
- Both themes: lockup lands correctly in `mixos` and `mixos-dark`.
- `npm run lint`, `npm run typecheck`, `npm run build`.
